# Hi, I'm Mindy.

I deploy enterprise AI systems for Fortune 500 media companies by day — RAG pipelines, agent platforms, the unglamorous work of getting an AI system from proof-of-concept to something 3,000 people actually use. Outside of that I build small, finished things, mostly to answer questions I was curious about myself.

CS & Data Science, NYU. Based in New York.

## Things I've built

- **[career-fit](https://github.com/mindyjwu/career-fit)** — a job-search tool I built because LinkedIn's filters don't actually work. Give it a job posting and my profile, it returns a real multi-dimensional fit score with a narrative explanation, not a keyword match.
- **[Mindy's AI Guide](https://mindys-ai-guide.vercel.app)** — teaches non-technical people how to use Claude for everyday things. Built because my parents kept asking if AI was coming for their jobs.
- **[Stock Advisor](https://github.com/mindyjwu/stock_advisor)** — a multi-user investing dashboard with transparent, explainable scoring instead of a black-box "buy" button.
- **[GenAI](https://github.com/mindyjwu/gender-ai)** — two AI personas, different communication styles, and a report on which one you actually trust more.
- **[Global Explorer](https://global-explorer-ivory.vercel.app)** — a 3D globe for browsing 1,100+ cities, built because most travel sites bury the fun part under login walls.
